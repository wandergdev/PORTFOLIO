# Portafolio — Wander Genao

Portafolio personal construido con Next.js (App Router) y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Estructura

- `src/data/portfolio.ts` — contenido editable: bio, skills, experiencia y proyectos.
- `src/components/` — secciones de la página (Hero, About, Skills, Experience, Projects, Contact).
- `docs_notes_ideas.md` — notas originales sobre ideas de proyectos para el portafolio.

## Deploy

Pensado para desplegarse en [Vercel](https://vercel.com/new).
